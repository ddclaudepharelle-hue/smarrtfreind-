# SmartFriend

Application EdTech de révision (cours, quiz adaptatifs avec répétition espacée, banque d'épreuves en mode chrono, fiches partagées, tableau de bord).

Prototype web en un seul fichier : `index.html`.

## Publier avec GitHub Pages
1. Créez un dépôt `smartfriend` sur GitHub et envoyez ces fichiers.
2. Settings > Pages > Source : "GitHub Actions".
3. Le workflow `.github/workflows/pages.yml` déploie automatiquement à chaque push sur `main`.

Lien final : `https://VOTRE-PSEUDO.github.io/smartfriend/`
